# CarbonSutra API Documentation

Developer documentation for the **CarbonSutra API**, built with [Zudoku](https://zudoku.dev/docs).

CarbonSutra provides APIs for calculating and consolidating **carbon dioxide equivalent (CO₂e) emissions** across business activities such as business travel, accommodation, transportation, electricity, fuel, freight, and eCommerce shipments.

## Getting Started

### Prerequisites

Make sure you have **Node.js** installed on your system.

### Install Dependencies

Install the project dependencies:

```bash
npm install
```
