# Rapid Clustering

Developers can eliminate the need to store emission calculation results by assigning a self-declared tag to it. These tags are called cluster names and they can be added to any calculation within CarbonSutra. The endpoint: /cluster-data accepts the name of this tag and gives the output of all calculations in granular format in JSON.

For example, say a company calculates emissions for business travel (air and land), electricity consumption, hotel stays and their vehicle fleet, once every quarter. Using this self-defined label as an additional input parameter, these calculations can be clustered into sets and retrieved.

## Retrieval Logic

The JSON data for cluster name is retrieved for the request which has the same API key or Bearer Token as the ones which performed the calculation. The same API is being used for the interoperability format of OpenCCF.
