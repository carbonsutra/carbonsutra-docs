# Getting Started

Get started with the CarbonSutra API and integrate carbon emission estimation into your applications.

CarbonSutra provides APIs for estimating carbon emissions across flights, hotels, vehicles, freight, fuel, electricity, eCommerce, and other activities.

## 1. Get your API credentials

CarbonSutra APIs use an API key for authenticated requests.

If you already have an API key, you can start making requests immediately.

For APIs that do not require authentication, you can call the endpoint directly.

> Keep your API key secure. Do not expose it in frontend applications, public repositories, or client-side code.

## 2. Configure the API URL

Store the CarbonSutra API base URL in an environment variable.

```env
VITE_API_URL=YOUR_API_BASE_URL
```
